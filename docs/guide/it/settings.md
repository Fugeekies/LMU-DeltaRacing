# Options (*Impostazioni*)

| Impostazione | A cosa serve |
|---|---|
| **Dossier des résultats XML** (*Cartella dei risultati*) | Dove il gioco salva i tuoi risultati, di solito `Documents\Le Mans Ultimate\UserData\Log\Results`. Sceglila con **Parcourir…** (*Sfoglia*), poi **Appliquer** (*Applica*). Vuota: rilevamento automatico. |
| **Pilote principal** (*Pilota principale*) | Il pilota che segui (tu). L'elenco è ordinato per numero di presenze. |
| **Fusion de pilotes** (*Unione di piloti*) | Hai cambiato nickname? Scegli il vecchio nome e quello da tenere, poi **Fusionner** (*Unisci*). I tuoi file non vengono modificati e l'unione si può annullare. Compare un avviso se i due nomi hanno corso insieme. |
| **Démarrage automatique** (*Avvio automatico*) | Monitorare i nuovi risultati fin dall'avvio (attivo per impostazione predefinita). |
| **Sessions d'essais** (*Sessioni di prova*) | Caricare anche le prove per la scheda **ESSAIS** del [Dettaglio gare](race-details.md) (disattivato per impostazione predefinita). |
| **Mises à jour** (*Aggiornamenti*) | Versione installata e download della nuova. All'avvio l'applicazione chiede a GitHub il numero dell'ultima versione; togli la spunta per non farlo più. |

Sotto le impostazioni, lo **stato delle importazioni** mostra il caricamento, i file illeggibili e le sessioni recenti.

Le impostazioni sono salvate in `appsettings.json`, nella cartella di installazione (`%LOCALAPPDATA%\Programs\LMU-DeltaRacing`).
