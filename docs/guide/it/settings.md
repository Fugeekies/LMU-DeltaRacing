# Impostazioni

| Impostazione | A cosa serve |
|---|---|
| **Cartella dei risultati XML** | Dove il gioco salva i tuoi risultati, di solito `Documents\Le Mans Ultimate\UserData\Log\Results`. Sceglila con **Sfoglia…**, poi **Applica**. Vuota: rilevamento automatico. |
| **Lingua e data** | **Lingua dell’interfaccia**: English, Français, Deutsch, Italiano o Español (per impostazione predefinita la lingua di Windows, altrimenti l’inglese). **Formato della data**: secondo la lingua, oppure giorno/mese, mese/giorno, ISO, giorno.mese. La pagina si ricarica; i tempi sul giro e i numeri non cambiano. |
| **Pilota principale** | Il pilota che segui (tu). L'elenco è ordinato per numero di presenze. |
| **Unione di piloti** | Hai cambiato nickname? Scegli il vecchio nome e quello da tenere, poi **Unisci**. I tuoi file non vengono modificati e l'unione si può annullare. Compare un avviso se i due nomi hanno corso insieme. |
| **Avvio automatico** | Monitorare i nuovi risultati fin dall'avvio (attivo per impostazione predefinita). |
| **Sessioni caricate** | **Carica le sessioni di prova**: anche le prove, per la scheda **PROVE LIBERE** del [Dettaglio gare](race-details.md). **Carica le gare offline contro l’IA**: anche le tue gare in solitaria (modalità «Race Weekend» del gioco), escluse per non falsare il rating pilota e le statistiche tra giocatori. Entrambe sono disattivate per impostazione predefinita; i risultati si ricaricano appena metti o togli la spunta. |
| **Aggiornamenti** | Versione installata e download della nuova. All'avvio l'applicazione chiede a GitHub il numero dell'ultima versione; togli la spunta per non farlo più. |

Sotto le impostazioni, lo **stato delle importazioni** mostra il caricamento, i file illeggibili e le sessioni recenti.

Le impostazioni sono salvate in `appsettings.json`, nella cartella di installazione (`%LOCALAPPDATA%\Programs\LMU-DeltaRacing`).
