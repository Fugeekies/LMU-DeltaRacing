# Installazione e primo avvio

## Installare

**Requisiti:** Windows a 64 bit, nient'altro.

1. Scarica `LMU-DeltaRacing-Setup.exe` dalla pagina [Releases](https://github.com/Fugeekies/LMU-DeltaRacing/releases).
2. Avvialo. L'installazione avviene nel tuo profilo Windows, senza diritti di amministratore.
   > Windows può mostrare un avviso SmartScreen perché il programma di installazione non è firmato: fai clic su **Ulteriori informazioni**, poi su **Esegui comunque**.
3. Se vuoi, spunta **Créer une icône sur le bureau** (*crea un'icona sul desktop*), poi termina.

Il programma di installazione cerca la cartella in cui il gioco salva i tuoi risultati (Documenti e cartella Steam del gioco). Se non ne trova, installa dei **dati dimostrativi**; sceglierai la cartella giusta nelle [Impostazioni](settings.md).

## Primo avvio

Avvia **LMU-DeltaRacing** dal menu Start o dal desktop.

- La dashboard si apre **nel tuo browser**.
- Si apre anche una **finestra nera**: è l'applicazione. **Chiuderla arresta l'applicazione**; chiudere la scheda del browser non basta.
- Mentre i file vengono letti appare una schermata di caricamento, poi l'indicatore in alto a destra passa a **SURVEILLANCE ACTIVE** (*monitoraggio attivo*).
- **Il tuo pilota viene rilevato automaticamente**: il nome presente nel maggior numero di file. Se è sbagliato, cambialo in **Options › Pilote principal** (*Pilota principale*).

Lascia l'applicazione aperta mentre giochi: ogni sessione conclusa compare da sola.

## Aggiornare, disinstallare

- **Aggiornamento:** all'avvio una finestra ti avvisa quando esce una nuova versione. Scaricala da **Options › Mises à jour** (*Aggiornamenti*) e installala sopra la vecchia: le impostazioni vengono conservate.
- **Disinstallazione:** *Impostazioni di Windows › App*, come qualsiasi programma.
