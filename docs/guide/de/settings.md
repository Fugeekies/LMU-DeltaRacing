# Options (*Einstellungen*)

| Einstellung | Wozu sie dient |
|---|---|
| **Dossier des résultats XML** (*Ergebnisordner*) | Wo das Spiel Ihre Ergebnisse speichert, meist `Documents\Le Mans Ultimate\UserData\Log\Results`. Wählen Sie ihn mit **Parcourir…** (*Durchsuchen*) und dann **Appliquer** (*Übernehmen*). Leer: automatische Erkennung. |
| **Pilote principal** (*Hauptfahrer*) | Der Fahrer, dem Sie folgen (Sie selbst). Die Liste ist nach Anzahl der Auftritte sortiert. |
| **Fusion de pilotes** (*Fahrer zusammenführen*) | Spitznamen geändert? Wählen Sie den alten und den beibehaltenen Namen, dann **Fusionner** (*Zusammenführen*). Ihre Dateien werden nicht verändert und die Zusammenführung lässt sich rückgängig machen. Eine Warnung erscheint, wenn beide Namen zusammen gefahren sind. |
| **Démarrage automatique** (*Autostart*) | Neue Ergebnisse ab dem Start überwachen (standardmäßig an). |
| **Sessions d'essais** (*Trainingssessions*) | Auch das Training für den Reiter **ESSAIS** der [Renndetails](race-details.md) laden (standardmäßig aus). |
| **Mises à jour** (*Updates*) | Installierte Version und Download der neuen. Die Anwendung fragt beim Start bei GitHub die Nummer der neuesten Version ab; Häkchen entfernen, um das abzustellen. |

Unter den Einstellungen zeigt der **Importstatus** den Ladefortschritt, unlesbare Dateien und Ihre letzten Sessions.

Die Einstellungen werden in `appsettings.json` im Installationsordner gespeichert (`%LOCALAPPDATA%\Programs\LMU-DeltaRacing`).
