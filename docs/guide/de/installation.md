# Installation und erster Start

## Installieren

**Voraussetzungen:** Windows 64 Bit, sonst nichts.

1. Laden Sie `LMU-DeltaRacing-Setup.exe` von der Seite [Releases](https://github.com/Fugeekies/LMU-DeltaRacing/releases) herunter.
2. Starten Sie die Datei. Die Installation erfolgt in Ihrem Windows-Profil, ohne Administratorrechte.
   > Windows kann eine SmartScreen-Warnung anzeigen, weil das Installationsprogramm nicht signiert ist: Klicken Sie auf **Weitere Informationen** und dann auf **Trotzdem ausführen**.
3. Aktivieren Sie bei Bedarf **Créer une icône sur le bureau** (*Desktop-Verknüpfung erstellen*) und schließen Sie die Installation ab.

Das Installationsprogramm sucht den Ordner, in dem das Spiel Ihre Ergebnisse speichert (Dokumente und Steam-Ordner des Spiels). Findet es keinen, installiert es **Demodaten**; den richtigen Ordner wählen Sie dann in den [Einstellungen](settings.md).

## Erster Start

Starten Sie **LMU-DeltaRacing** über das Startmenü oder den Desktop.

- Das Dashboard öffnet sich **in Ihrem Webbrowser**.
- Außerdem öffnet sich ein **schwarzes Fenster**: Das ist die Anwendung. **Wenn Sie es schließen, wird die Anwendung beendet**; den Browser-Tab zu schließen reicht nicht.
- Während Ihre Dateien gelesen werden, erscheint ein Ladebildschirm; danach zeigt die Anzeige oben rechts **SURVEILLANCE ACTIVE** (*Überwachung aktiv*).
- **Ihr Fahrer wird automatisch erkannt**: der Name, der in den meisten Dateien vorkommt. Ist er falsch, ändern Sie ihn unter **Options › Pilote principal** (*Hauptfahrer*).

Lassen Sie die Anwendung beim Spielen geöffnet: Jede beendete Session erscheint von selbst.

## Aktualisieren, deinstallieren

- **Aktualisierung:** Beim Start weist Sie ein Fenster auf eine neue Version hin. Laden Sie sie unter **Options › Mises à jour** (*Updates*) herunter und installieren Sie sie über die alte: Ihre Einstellungen bleiben erhalten.
- **Deinstallation:** *Windows-Einstellungen › Apps*, wie bei jedem Programm.
