# Progression (*Fortschritt*)

Ein Diagramm der Entwicklung Ihrer besten Runden auf einer Strecke, in einer Klasse.

- Wählen Sie **circuit** (*Strecke*) und **catégorie** (*Klasse*): Die Seite öffnet sich mit denen Ihres letzten Rennens.
- **Période** (*Zeitraum*): Tag, Woche, Monat oder Jahr.
- **Valeur tracée** (*Dargestellter Wert*): der beste (min), der Durchschnitt oder der schlechteste (max) Wert jedes Zeitraums; das farbige Band reicht von min bis max.
- **Affichage** (*Anzeige*): eine Kurve für Rennen und eine für Qualifying, oder eine Kurve pro Auto.
- Die **Zusammenfassung** nennt für jede Kurve Ihren Rekord, den Anfangswert, den aktuellen Wert und den Abstand.
- Klicken Sie auf einen Legendeneintrag, um eine Kurve auszublenden; **Afficher le détail des périodes** (*Zeiträume im Detail*) zeigt die genauen Werte.

Ihre Einstellungen werden für das nächste Mal gespeichert.
