# Benutzerhandbuch

LMU DeltaRacing liest die Ergebnisdateien, die *Le Mans Ultimate* nach jeder Session speichert, und macht daraus ein persönliches Dashboard. Alles bleibt auf Ihrem PC: **Es werden keine Daten gesammelt**.

> Die Anwendung ist auf Französisch. Dieses Handbuch zitiert die Bildschirmbeschriftungen so, wie sie erscheinen, gefolgt von ihrer Übersetzung: **Mes courses** (*Meine Rennen*).

## Erste Schritte

- [Installation und erster Start](installation.md)
- [Einstellungen](settings.md)
- [Häufige Fragen](faq.md)

## Die Seiten des Dashboards

| Seite | Kurz gesagt |
|---|---|
| [Accueil](home.md) (*Startseite*) | Ihre Karriere auf einen Blick |
| [Mes courses](my-races.md) (*Meine Rennen*) | Ihre Historie, Strecke für Strecke |
| [Détail des courses](race-details.md) (*Renndetails*) | Das vollständige Klassement eines Events, Sektor für Sektor |
| [Progression](progression.md) (*Fortschritt*) | Die Entwicklung Ihrer besten Runden auf einer Strecke |
| [Profil de conduite](driving-profile.md) (*Fahrprofil*) | Ihre Kontakte, Track Limits und Strafen |
| [Cote pilote](driver-rating.md) (*Fahrerwertung*) | Ihr Niveau, gemessen mit einer Elo-Wertung |
| [Classement des coureurs](drivers-ranking.md) (*Direktvergleich*) | Ihre Bilanz gegen jeden Gegner |

**In allen Tabellen** ziehen Sie den Griff am rechten Rand einer Spaltenüberschrift, um die Spalte breiter oder schmaler zu machen; ein Doppelklick auf diesen Rand stellt die ursprünglichen Breiten wieder her.
