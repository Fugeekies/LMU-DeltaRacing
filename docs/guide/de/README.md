# Benutzerhandbuch

LMU DeltaRacing liest die Ergebnisdateien, die *Le Mans Ultimate* nach jeder Session speichert, und macht daraus ein persönliches Dashboard. Alles bleibt auf Ihrem PC: **Es werden keine Daten gesammelt**.

> Die Anwendung spricht Englisch, Französisch, Deutsch, Italienisch und Spanisch: Wählen Sie die Sprache unter **Einstellungen › Sprache und Datum**.

- [Einstellungen](settings.md)
- [Häufige Fragen](faq.md)

## Die Seiten des Dashboards

| Seite | Kurz gesagt |
|---|---|
| [Startseite](home.md) | Ihre Karriere auf einen Blick |
| [Meine Rennen](my-races.md) | Ihre Historie, Strecke für Strecke |
| [Renndetails](race-details.md) | Das vollständige Klassement eines Events, Sektor für Sektor |
| [Fortschritt](progression.md) | Die Entwicklung Ihrer besten Runden auf einer Strecke |
| [Fahrprofil](driving-profile.md) | Ihre Kontakte, Track Limits und Strafen |
| [Fahrerwertung](driver-rating.md) | Ihr Niveau, gemessen mit einer Elo-Wertung |
| [Direktvergleich](drivers-ranking.md) | Ihre Bilanz gegen jeden Gegner |

**In allen Tabellen** ziehen Sie den Griff am rechten Rand einer Spaltenüberschrift, um die Spalte breiter oder schmaler zu machen; ein Doppelklick auf diesen Rand stellt die ursprünglichen Breiten wieder her.
