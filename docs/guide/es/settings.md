# Options (*Ajustes*)

| Ajuste | Para qué sirve |
|---|---|
| **Dossier des résultats XML** (*Carpeta de resultados*) | Dónde guarda el juego tus resultados, normalmente `Documents\Le Mans Ultimate\UserData\Log\Results`. Elígela con **Parcourir…** (*Examinar*) y luego **Appliquer** (*Aplicar*). Vacía: detección automática. |
| **Pilote principal** (*Piloto principal*) | El piloto que sigues (tú). La lista se ordena por número de apariciones. |
| **Fusion de pilotes** (*Fusión de pilotos*) | ¿Has cambiado de apodo? Elige el nombre antiguo y el que se conserva, y luego **Fusionner** (*Fusionar*). Tus archivos no se modifican y la fusión se puede deshacer. Aparece un aviso si los dos nombres han corrido juntos. |
| **Démarrage automatique** (*Inicio automático*) | Vigilar los nuevos resultados desde el inicio (activado por defecto). |
| **Sessions d'essais** (*Sesiones de libres*) | Cargar también los libres para la pestaña **ESSAIS** del [Detalle de carreras](race-details.md) (desactivado por defecto). |
| **Mises à jour** (*Actualizaciones*) | Versión instalada y descarga de la nueva. Al iniciar, la aplicación pregunta a GitHub el número de la última versión; desmarca la casilla para dejar de hacerlo. |

Debajo de los ajustes, el **estado de las importaciones** muestra la carga, los archivos ilegibles y tus sesiones recientes.

Los ajustes se guardan en `appsettings.json`, en la carpeta de instalación (`%LOCALAPPDATA%\Programs\LMU-DeltaRacing`).
