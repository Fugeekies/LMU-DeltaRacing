# Questions fréquentes

**Je ne vois aucune course.**
Dans **Options**, vérifiez que le dossier des résultats affiche « Dossier valide » et que le **pilote principal** est bien votre nom dans le jeu.

**Je vois des pilotes « Driver Tom », « Driver Lucas »…**
Ce sont les données de démonstration. Choisissez votre dossier de résultats dans **Options**, puis **Appliquer**.

**Une session que je viens de finir n'apparaît pas.**
Le jeu écrit le fichier à la **fin** de la session. Vérifiez que l'indicateur affiche **SURVEILLANCE ACTIVE**, sinon cliquez sur **Appliquer** dans Options.

**Mon historique est coupé en deux depuis que j'ai changé de pseudo.**
Utilisez **Options › Fusion de pilotes**.

**Pourquoi ma voiture n'est-elle pas comparée à toutes les autres ?**
Les comparaisons se font **par catégorie**, comme en endurance : une GT3 est comparée aux GT3.

**J'ai fermé le navigateur, comment rouvrir le tableau de bord ?**
Fermez la fenêtre noire de l'application si elle est ouverte, puis relancez **LMU-DeltaRacing**.

**Où trouver le journal en cas de problème ?**
`lmu-deltaracing.log`, dans le dossier d'installation. Il est remplacé à chaque lancement.

**Mes données sont-elles envoyées quelque part ?**
Non. Le tableau de bord n'est accessible que depuis votre PC. La seule requête vers Internet demande à GitHub le numéro de la dernière version, et se désactive dans les [Options](settings.md).
