# Installation et premier lancement

## Installer

**Configuration requise :** Windows 64 bits, rien d'autre.

1. Téléchargez `LMU-DeltaRacing-Setup.exe` depuis la page [Releases](https://github.com/Fugeekies/LMU-DeltaRacing/releases).
2. Lancez-le. L'installation se fait dans votre profil Windows, sans droits administrateur.
   > Windows peut afficher un avertissement SmartScreen, car l'installeur n'est pas signé : cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
3. Cochez si vous voulez **Créer une icône sur le bureau**, puis terminez.

L'installeur cherche le dossier où le jeu enregistre vos résultats (Documents et dossier Steam du jeu). S'il n'en trouve aucun, il installe des **données de démonstration** ; vous choisirez le bon dossier dans les [Options](settings.md).

## Premier lancement

Lancez **LMU-DeltaRacing** depuis le menu Démarrer ou le bureau.

- Le tableau de bord s'ouvre **dans votre navigateur**.
- Une **fenêtre noire** s'ouvre aussi : c'est l'application. **La fermer arrête l'application** ; fermer l'onglet du navigateur ne suffit pas.
- Un écran de chargement s'affiche le temps de lire vos fichiers, puis l'indicateur en haut à droite passe à **SURVEILLANCE ACTIVE**.
- **Votre pilote est détecté automatiquement** : le nom présent dans le plus de fichiers. S'il est faux, changez-le dans **Options › Pilote principal**.

Laissez l'application ouverte pendant que vous jouez : chaque session terminée apparaît toute seule.

## Mettre à jour, désinstaller

- **Mise à jour :** une fenêtre vous prévient au démarrage quand une version sort. Téléchargez-la depuis **Options › Mises à jour** et installez-la par-dessus : vos réglages sont conservés.
- **Désinstallation :** *Paramètres Windows › Applications*, comme tout programme.
