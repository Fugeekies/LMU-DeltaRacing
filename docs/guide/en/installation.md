# Installation and first launch

## Install

**Requirements:** 64-bit Windows, nothing else.

1. Download `LMU-DeltaRacing-Setup.exe` from the [Releases](https://github.com/Fugeekies/LMU-DeltaRacing/releases) page.
2. Run it. It installs into your Windows profile, without administrator rights.
   > Windows may show a SmartScreen warning because the installer is not signed: click **More info**, then **Run anyway**.
3. Tick **Créer une icône sur le bureau** (*create a desktop shortcut*) if you wish, then finish.

The installer looks for the folder where the game saves your results (Documents and the game's Steam folder). If it finds none, it installs **demo data**; you will pick the right folder in the [Settings](settings.md).

## First launch

Start **LMU-DeltaRacing** from the Start menu or the desktop.

- The dashboard opens **in your web browser**.
- A **black window** opens too: it is the application. **Closing it stops the application**; closing the browser tab is not enough.
- A loading screen shows while your files are read, then the indicator at the top right turns to **SURVEILLANCE ACTIVE** (*watching*).
- **Your driver is detected automatically**: the name found in the most files. If it is wrong, change it in **Options › Pilote principal** (*Main driver*).

Keep the application open while you play: each finished session shows up on its own.

## Update, uninstall

- **Update:** a window tells you at startup when a new version is out. Download it from **Options › Mises à jour** (*Updates*) and install it over the old one: your settings are kept.
- **Uninstall:** *Windows Settings › Apps*, like any program.
