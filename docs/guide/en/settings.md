# Options (*Settings*)

| Setting | What it does |
|---|---|
| **Dossier des résultats XML** (*Results folder*) | Where the game saves your results, usually `Documents\Le Mans Ultimate\UserData\Log\Results`. Pick it with **Parcourir…** (*Browse*), then **Appliquer** (*Apply*). Empty: automatic detection. |
| **Pilote principal** (*Main driver*) | The driver you follow (you). The list is sorted by number of appearances. |
| **Fusion de pilotes** (*Driver merge*) | Changed your nickname? Pick the old name and the kept name, then **Fusionner** (*Merge*). Your files are not modified and the merge can be undone. A warning shows if both names raced together. |
| **Démarrage automatique** (*Auto start*) | Watch for new results from launch (on by default). |
| **Sessions d'essais** (*Practice sessions*) | Also load practice for the **ESSAIS** tab of [Race details](race-details.md) (off by default). |
| **Mises à jour** (*Updates*) | Installed version and download of the new one. The application asks GitHub for the latest version number at startup; untick to stop. |

Below the settings, the **import status** shows loading progress, unreadable files and your recent sessions.

Settings are saved in `appsettings.json`, in the installation folder (`%LOCALAPPDATA%\Programs\LMU-DeltaRacing`).
